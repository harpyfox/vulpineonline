About this site

VULPINE ONLINE is my portfolio website. you're looking at it right now!

this site is entirely hand-written. Jinja2 is used to avoid copy-pasting the same <head> element to every page.

this site is hosted with Cloudflare Workers. the documentation for their static site solution is a bit lacking, and you can tell it's kind of a shoe-in to try and deprecate Cloudflare Pages. but it works well enough, and it's free. for now, at least.

javascript is minimal. the site functions without it.

github is used for version control. it deploys automatically when a push is made to the repository.
isn't that nice.
